A Python script that reads your monthly Qualtrics CSV export, sends the raw responses to Claude for analysis, and outputs a .pptx slide deck with 3–5 prioritized, consulting-style insights — each framed as a "so what" with supporting evidence and a recommendation. Replaces the manual Excel analysis and slide-writing entirely.

Sub-builds
1 — CSV → Prioritized Insights
Reads Qualtrics export, passes responses to Claude, returns ranked insight list with business framing. Done when: 3–5 numbered insight bullets print to stdout. ~1–2 hrs.
2 — Insights → PowerPoint
Takes Claude output, generates a .pptx — one slide per insight, title = headline finding, body = evidence + recommendation. Done when: file opens in PowerPoint with clean, readable slides. ~1–2 hrs.
